# Cosmetic AI Assistant

Type in a cosmetic product's name (and model, if it has one), and get back:

- Ingredients
- Uses & benefits
- Directions to use, in simple steps
- Which skin type it suits
- Expiration / shelf-life info

## Status

v1 -- skeleton only. Takes a product name as input, doesn't look anything up yet.
Real lookup logic is being added step by step.

## Run it

python app.py "CeraVe Moisturizing Cream"
